DSE 概念辨析筆記

唔係再教一次課文，而係專門拆解學生最常錯嘅地方。每條用「常見誤解 → 正確講法 → 為何會錯」三段處理。

Circular Motion

圓周運動

Misconception 01向心力係一種「真實力」

常見誤解物體作圓周運動時，除咗重力、張力之外，仲有一種叫「向心力」嘅力作用在物體上。
正確講法向心力唔係新一種力，而係「合力嘅角色」。真正提供向心力嘅一定係某個實際力：繩的張力、路面的摩擦力、路軌的法向力、重力、或者磁力。

為何重要：DSE 長題目要求你寫出方程 T = mv²/r、f = mv²/r 或 N sinθ = mv²/r，而唔係「F_c = mv²/r」就算完成。只寫 centripetal force 而唔指明邊個力，通常拿唔到分。
自檢：寫方程前先問一句「呢個圓周運動係邊個力拉住佢？」答得出，方程就寫得出。

Misconception 02轉彎時有「離心力」把你推向外

常見誤解汽車轉彎時，乘客被「離心力」推向外側，所以應該寫 centrifugal force 作用在乘客身上。
正確講法離心力係非慣性參考系下的假想力，DSE 不接受。乘客外傾係因為慣性（inertia）：身體想沿切線方向直線前進，但座椅／車門施加向內的力令佢轉向。

為何重要：答案出現 centrifugal force 通常直接扣分。正確敘述：「乘客趨向沿切線方向運動（慣性），車廂向內加速，故乘客相對車廂外傾。」
自檢：「呢個力有冇施力者？」答唔出，就係假想力。

Misconception 03速率不變就代表合力為零

常見誤解等速率圓周運動速率無變，所以加速度為零、合力為零。
正確講法加速度係向量。速度方向不斷改變，所以一定有加速度，而且恆指向圓心，大小 ac = v²/r。合外力大小為 mv²/r，方向指向圓心。

為何重要：呢個係 Newton's second law 的核心考核：合力決定加速度，唔係決定速率。物體可以有加速度但速率不變。
自檢：問「速度向量有冇變？」而唔係問「速率有冇變？」

Misconception 04圓錐擺越重，擺得越低（θ 越大）

常見誤解小球越重，繩會被拉得越低，所以 θ 會增加。
正確講法豎直 T cosθ = mg、水平 T sinθ = mω²r，兩式相除消去 m 得 tanθ = ω²r/g。θ 只由 ω 與 r 決定，與質量完全無關。質量只影響張力 T = mg/cosθ。

為何重要：呢條係 DSE 最愛的「隱藏消去」題型：明明加咗質量，但答案話「不變」，好多考生以為自己計錯而改答案。
自檢：列出兩條方程，再問「邊個未知數被消去？」

Misconception 05斜坡彎道上 N = mg

常見誤解路面的法向力永遠等於車重，即 N = mg。
正確講法只有在水平路面上 N = mg。有傾角的彎道上，車同時受向心加速度影響：N = mg cosθ + (mv²/r) sinθ，恆大於 mg cosθ。

為何重要：N 用錯會令摩擦力上限 μN 計錯，之後「會唔會打滑」的結論全錯。
自檢：凡見斜面就改用「垂直斜面」方向列方程，唔好直接寫 N = mg。

Misconception 06鉛垂圓周全程速率相同

常見誤解圓周運動速率不變，所以鉛垂圓周最高點與最低點速率一樣。
正確講法只有等速率圓周運動速率才不變。鉛垂圓周有重力作功，速率處處不同：最高點最慢、最低點最快，兩點關係由能量守恆給出 v_bot² = v_top² + 4gr（高度差 = 直徑 = 2r）。

為何重要：用 v²/r 代入「同一個 v」係最常見的整題崩壞點。一定要分開 v_top 與 v_bot。
自檢：見到「鉛垂面」三個字，即刻寫能量守恆式，再寫徑向方程。
